# yug-avto-expert.ru — «Эксперт» (б/у автомобили)

Боевой корпоративный сайт на **1С-Битрикс** для направления «Эксперт» автохолдинга: **витрина автомобилей с пробегом (б/у) в наличии** и услуги выкупа автомобилей.

## Направление

- **Только б/у автомобили** в наличии — каталог с фильтрами
- **Выкуп автомобилей** (собственные подстраницы под марки: `/services/buyout/citroen/` и т.д.)
- Личный кабинет, блог, новости, корпоративные страницы
- Платёжные страницы (payfail / payreturn)

## Стек

- 1С-Битрикс (PHP), кастомные компоненты
- **Go API (v1)** — высокопроизводительный слой: каталог и случайные выборки (`/api/v1/cis/random`) вместо тяжёлых запросов PHP-монолита
- Cron-задачи: `cron/makeSitemap.php` — генерация sitemap + `llms.txt`
- SEO: плоский одноуровневый sitemap-индекс, robots.txt под структуру, self-canonical

## Структура

| Раздел | Назначение |
|--------|-----------|
| `cars/` | Каталог автомобилей (used/new → редирект на used) |
| `offers/` | Предложения / спецпредложения |
| `services/buyout/` | Услуги выкупа авто (подстраницы по маркам) |
| `cabinet/` | Личный кабинет клиента |
| `dealerships/` | Дилерская сеть |
| `api/` | API-слой (в т.ч. интеграция с Go API) |
| `cron/` | Фоновые задачи (sitemap, llms.txt) |
| `blog/`, `news/`, `corporate/` | Контентные разделы |

## Особенности реализации

- **Гибрид PHP + Go**: выдача каталога на Go API, обвязка и SEO — на Битриксе
- Защита от падений: валидация ответов API до вызова шаблонов (`is_array()`, 404/301 до рендера)
- Мгновенные 301 для /new → /used (б/у-фокус направления)
- Канонизация подстраниц выкупа (self-canonical, не корень)
- Автогенерация `llms.txt` (LLM-дружественная карта сайта)
