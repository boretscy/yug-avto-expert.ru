# Changelog - yug-avto-expert.ru (Эксперт)

## [2026-08-07]
### Added
- Внедрена автоматическая генерация файла `llms.txt` в корне сайта Эксперта в составе регулярного крона `cron/makeSitemap.php`.

### Changed
- Переведён вызов списка выкупленных автомобилей в `services/buyout/index.php` со старого эндпоинта PHP-монолита на современный высокопроизводительный эндпоинт Go API (v1) `/api/v1/cis/random` с лимитом `limit=12`.

### Fixed
- Удален неиспользуемый фильтр `dealership=1489` из компонента `main.cards.cars` (`result_modifier.php` и `script.js`).
- Убрана жесткая канонизация на корень в `services/buyout/index.php`. Теперь подстраницы выкупа (`/services/buyout/citroen/` и т.д.) имеют правильный self-canonical.

### Added
- Внедрена дефолтная авто-генерация тега `<link rel="canonical" href="...">` на самого себя (self-canonical) в `header.php` для всех статических страниц сайта с отсечением GET-параметров.

## [2026-08-04]
### Fixed
- Исправлена генерация URL в методе `makeFilterUrl` (`YApp.Showroom.class.php`):
  - При выборе одной модели формируется ЧПУ вида `/cars/used/avatr-11/` (или `/cars/used/avatr/avatr-11/`) без передачи параметров через GET.
  - Сохранён перенос модели в GET-параметр (`?model=avatr-11,avatr-12`) только при мультивыборе (2 и более моделей).

### Changed
- Внедрена нормализация и суммирование скидок на детальной странице авто (`cars/used/views/vehicle/vehicle.php`):
  - Приведение названий скидок к читаемым категориям («Трейд-ин», «Кредит», «Семейный автомобиль», «КАСКО в подарок», «Прямая скидка» и др.).
  - Автоматическое объединение скидок одного типа и суммирование их значений.

## [2026-08-03]
### Fixed
- Переключена витрина Эксперта (`cars/used/vendor/Config.php` и `YApp.Showroom.class.php`) с устаревшего PHP-монолита на Go API (`YApp::GO_API_DOMAIN`), что устранило 404 ошибку и привело алгоритм подмешивания CTA-карточек к единому стандарту с отступом `minGap = 12`.
- Исправлена пагинация витрины: при возврате на первую страницу ссылки теперь ведут в корень витрины без суффикса page-1/.
- Добавлен 301 редирект для URL, содержащих page-1, на соответствующий корневой адрес.

## [2026-08-03]
### Changed
- Модернизирована микроразметка Schema.org детальной страницы авто под стандарт JSON-LD (аналогично Авто.ру):
  - Переведено на единую сущность Product в формате JSON-LD с обогащенным описанием, массивом изображений, годом выпуска и карточкой продавца AutoDealer (ООО «Юг-Авто Эксперт»).
  - Из верстки (vehicle.php) полностью вычищены дублирующие HTML-атрибуты Microdata (itemscope, itemprop, itemtype).

## [2026-08-03]
### Deployed
- Успешный перенос пакета СЕО-доработок, микроразметки Schema.org/JSON-LD, 301-редиректов, заголовков Last-Modified и оптимизаций производительности на PROD-сервер (yug-avto-expert.ru).

## [2026-07-31]
### Added
- Оптимизация PageSpeed:
  - Внедрена ленивая (отложенная) загрузка сторонних виджетов (Calltouch, Talk-Me, widgets3-script) по первому пользовательскому действию для снижения Total Blocking Time (TBT).

### Changed
- Удален сторонний импорт шрифтов Google Fonts (`@import url(https://fonts.googleapis.com...)`) из `bootstrap.min.css` в шаблонах темы и промо Эксперта.
- Обновлено формирование атрибутов `alt` и `title` для изображений автомобилей:
  - В списочных карточках авто (каталог, избранное, сравнение, рекомендации) они теперь генерируются строго из наименования (Бренд + Модель) с добавлением индекса ракурса.
  - На детальной странице автомобиля они формируются на основе H1-заголовка, включающего бренд, модель, год выпуска и пробег.
- В `dealerships/index.php` добавлен вывод 404 страницы для обработки некорректных адресов дилерских центров.

### Fixed
- Исправлена синтаксическая ошибка при отсутствии куки `SELECTED_CITY` в `assets/js/app.js`: фоллбек `|| '[]'` вынесен внутрь `JSON.parse()`, что предотвращает выброс исключения `SyntaxError: "undefined" is not valid JSON` и блокировку инициализации `CONNECTOR.SELECTED_CITY` у новых пользователей.
- Устранено зависание/блокировка воркеров PHP-FPM при жесткой перезагрузке страницы выкупа (`/services/buyout/`): внешние вызовы API `file_get_contents` обёрнуты в кэширование Bitrix (`\Bitrix\Main\Data\Cache`) с таймаутом соединения 2 секунды.
- Переведены все небезопасные вызовы `file_get_contents()` для внешних REST API на метод `YApp::httpGet()` с cURL, повторными попытками и фиксированным таймаутом соединения.

## [2026-07-30]
### Added
- Внедрена сквозная микроразметка Schema.org для улучшения поисковой оптимизации (п. 10 ТЗ):
  - Хлебные крошки размечены по стандарту `BreadcrumbList` и `ListItem` (включая последнюю страницу).
  - Элементы верхнего и мобильного меню размечены как `SiteNavigationElement`, а шапка страницы как `WPHeader`.
  - Футер размечен как `WPFooter` с указанием `copyrightHolder` и `copyrightYear`.
  - На главной странице добавлена JSON-LD разметка `WebSite` (с потенциальным действием поиска `SearchAction`) и `AutoDealer`.
  - В детальный шаблон новостей внедрена микроразметка `NewsArticle` со свойствами `headline`, `image`, `datePublished`, `dateModified`, `publisher` и `articleBody`.
  - Список автомобилей в каталоге обернут в родительскую сущность `ItemList` с указанием `numberOfItems`.
  - Карточки объявлений приведены к формату `Product` с вложенным объектом `Offer` (раскомментированы и скорректированы `price`, `priceCurrency` и `availability`).
  - Детальная страница автомобиля приведена к стандарту `Product` со вложенным `Offer` для корректной индексации.

## [2026-07-29]
### Added
- Добавлен нетрекаемый конфигурационный файл `/local/php_interface/yapps_config.php` для локальной настройки доменов Go API на DEV и PROD серверах.
- В `.gitignore` добавлены правила исключения временных файлов настроек домена, логов и файлов ключей `.json`.
- В класс `YApp` добавлен недостающий вспомогательный метод `getCleanAltText()` для генерации alt-тегов изображений.

### Changed
- Класс `YApp` переведен на наследование от `YAppConfig` для автоматической подгрузки доменов без перезаписи при слиянии Git-веток.
- Настроен беспарольный пуш и деплой на GitHub по SSH напрямую с серверов разработки (`serverDEV`) и прод-сервера (`Holding`).

### Added
- Реализованы 301-редиректы с `index.php`, `index.html` и `index.htm` на главную страницу (`/`) и 301-редирект множественных слэшей в URL в `/local/php_interface/init.php` (п. 1 и п. 2 ТЗ).
- Добавлена отдача заголовков `Last-Modified` и `If-Modified-Since` (`304 Not Modified`) для статических страниц и разделов сайтов (п. 10 ТЗ).
- Внедрен глобальный тумблер `ENABLE_FRONTEND_OPTIMIZATION` в `init.php` с созданием и подключением минифицированных бандлов стилей `bundle.app.min.css` и скриптов `bundle.app.min.js`.
- Добавлены упреждающие `dns-prefetch` и `preconnect` для домена API `apps.yug-avto.ru` в `header.php` (п. 13 ТЗ).
- Обновлен генератор карты сайта `/cron/makeSitemap.php` на динамическое определение пути корня сайта (`$dd = dirname(__DIR__)`) и домена (`$domain`).
- Настроена отдельная страница `404Cis.php` для проданных авто с выводом кнопок перехода на главную витрину, бренд или бренд+модель на базе переданного из `cars/used/index.php` контекста фильтра.
- Добавлен метатег `canonical` со ссылкой на `https://etest.yug-avto.ru/services/buyout/` на странице услуги выкупа.
- Добавлена поддержка константы `YApp::SITE_DOMAIN` в методах класса `YAppShowroom` для возможности гибкого переопределения домена в GET-параметре `site` при запросах к API Cis (для подтягивания метатегов на DEV-серверах).

### Fixed
- Исправлен баг в карточках автомобилей на странице услуги выкупа `/services/buyout/`: обновлена верстка картинок (обернута в контейнеры для поддержки CSS zoom эффекта) и переписан JS-обработчик на переключение при движении мышки (`mousemove` + `touchmove`) с динамическим расчетом индекса картинок.
- Исправлена неполадка с неподгружением данных автосалона на детальной странице авто: переписан запрос на текущий хост `$_SERVER['HTTP_HOST']` вместо жесткого прод-домена, и добавлена очистка от BOM-символов (`\ufeff`) в ответе API перед парсингом `json_decode()`.
