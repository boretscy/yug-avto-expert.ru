# Changelog - yug-avto-expert.ru (Эксперт)

## [2026-07-29]
### Added
- Добавлен нетрекаемый конфигурационный файл `/local/php_interface/yapps_config.php` для локальной настройки доменов Go API на DEV и PROD серверах.
- В `.gitignore` добавлены правила исключения временных файлов настроек домена, логов и файлов ключей `.json`.
- В класс `YApp` добавлен недостающий вспомогательный метод `getCleanAltText()` для генерации alt-тегов изображений.

### Changed
- Класс `YApp` переведен на наследование от `YAppConfig` для автоматической подгрузки доменов без перезаписи при слиянии Git-веток.
- Настроен беспарольный пуш и деплой на GitHub по SSH напрямую с серверов разработки (`serverDEV`) и прод-сервера (`Holding`).

### Added
- Реализованы 301-редиректы с `index.php`, `index.html` и `index.htm` на главную страницу (`/`) и 301-редирект множественных слэшей в URL в `/local/php_interface/init.php` (п. 1 и п. 2 ТЗ).
- Добавлена отдача заголовков `Last-Modified` и `If-Modified-Since` (`304 Not Modified`) для статических страниц и разделов сайтов (п. 10 ТЗ).
- Внедрен глобальный тумблер `ENABLE_FRONTEND_OPTIMIZATION` в `init.php` с созданием и подключением минифицированных бандлов стилей `bundle.app.min.css` и скриптов `bundle.app.min.js`.
- Добавлены упреждающие `dns-prefetch` и `preconnect` для домена API `apps.yug-avto.ru` в `header.php` (п. 13 ТЗ).
- Обновлен генератор карты сайта `/cron/makeSitemap.php` на динамическое определение пути корня сайта (`$dd = dirname(__DIR__)`) и домена (`$domain`).

### Fixed
- Исправлен баг в карточках автомобилей на странице услуги выкупа `/services/buyout/`: обновлена верстка картинок (обернута в контейнеры для поддержки CSS zoom эффекта) и переписан JS-обработчик на переключение при движении мышки (`mousemove` + `touchmove`) с динамическим расчетом индекса картинок.
